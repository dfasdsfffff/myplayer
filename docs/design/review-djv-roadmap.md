## 阶段二：多素材与 A/B 对比

先定义独立会话生命周期、时间基准、对齐偏移、不同长度/帧率下的同步语义及资源预算，再实现素材列表、双视图并排、擦除、叠加、差分和参考帧。不能以两个独立播放按钮冒充同步审阅。

## 阶段三：专业媒体和色彩

扩展源格式抽象、图像序列发现/缺帧策略、有理数时间和帧索引；评估 EXR/DPX、OCIO 依赖与许可证、GPU/内存预算。高位深需要从解码、缓存、变换一直到渲染保持精度，不能把 8-bit SDL 画面加“色彩管理”开关作为实现。连续倒放、严格音视频区间和往返循环需要 Core 专项，不由 UI 定时 seek 模拟。

## 阶段四：高级审阅与交付

绘制标注、波形/缩略图/缓存展示、多轨和 OTIO、第二显示窗口、可移植导出及便携发行。每项需端到端测试和兼容性说明；不预先增加无实际功能的占位按钮。

## 第一阶段验收与限制

独立 MSVC Release 构建及五项相关测试已执行通过；实际 Windows 应用已通过测试视频和 UI Automation 验证播放画面、1:1/适应窗口及时间线/标注呈现。测试命令和范围见 [应用 README](../../apps/review/README.md)。

当前 I/O 仅本次媒体会话有效，不持久化到工程。区间近似、非无缝，不保证视频/音频严格不越出点。当前帧步进长片后段可能慢，普通 seek 不保证显示目标帧。尚未完成全格式、长时稳定性、主观音质或独立便携发行验收。
