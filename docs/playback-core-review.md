# 播放核心待优化与待验证事项

日期：2026-11-05。范围：play_core，以及 Qt 视频显示与帧邮箱调用链。

## 性能优化点（不是已测量的瓶颈）

- D-005：硬件帧经 av_hwframe_transfer_data 回到系统内存，再上传 SDL 纹理。零拷贝需要新的硬件纹理互操作设计，不适合未经基准直接替换显示后端。
- D-006：帧邮箱在转换完成后覆盖旧帧，不能避免已发生的转换开销。将丢帧前移涉及同步和帧所有权，应先测转换/覆盖/显示指标。
- D-007（剩余部分）：视频转换热路径仍有 AVFrame 分配和共享引用开销。应先测量分配成本，再决定是否引入可回收的 AVFrame 池。

## 待验证线索

- 倍速播放时 SoundTouch 和滤镜的 EOF 尾部排空。
- 暂停/恢复时 SDL 已缓冲音频与音频时钟重锚定。
- AVChannelLayout 自定义布局的深拷贝与释放。
- SoundTouch 参数、网络超时及 PacketQueue 计数的极端值边界。需区分包装接口缺陷与实际播放入口可达性。

这些线索尚未确认是实际播放故障，需要专项验证。
