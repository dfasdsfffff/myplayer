# MyPlayer Release Candidate Evidence

## Automated evidence

- Portable ZIP and SHA-256 sidecar are generated by `scripts/package-portable.ps1`.
- The packager checks required files, rejects Debug DLLs, and smoke-tests the staged executable.
- CI runs Debug and Release CTest and uploads the portable artifact.
- Local compatibility evidence (2026-11-03): 23 media/decode cases passed;
  actual H.264/H.265 D3D11 frames and CPU transfers were verified on Intel Arc.
  See [compatibility verification](../player-qa-checklist.md#compatibility-verification--2026-11-03)
  for scope and limitations. NVIDIA/other target adapters and device-creation
  failure recovery remain unverified, so the hardware publication gate stays open.

## Publication gates

- [ ] Code-signing certificate and signed executable verification.
- [ ] Clean Windows profile: extract, launch, play media, and delete the extracted directory.
- [ ] Eight-hour local-media playback evidence.
- [ ] Eight-hour network-media playback evidence.
- [ ] Hardware-decoding coverage on target hardware.

Do not present this artifact as publicly release-ready until every gate has evidence.
